# NIVARA — A More Complete Life

A luxury editorial-style static website for Nivara.

## Files
- `index.html` — page structure and content
- `style.css` — responsive luxury navy / champagne-gold design
- `script.js` — mobile navigation, year and newsletter interaction
- `nivara-logo.png` — supplied Nivara logo

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a GitHub repository named `nivara-website`.
2. Upload all four files to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Set deployment to **Deploy from a branch**, choose `main`, `/ (root)`, then save.
5. Your public site will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/nivara-website/`

The site is intentionally built as a static site so it can later be upgraded with real products, checkout, WhatsApp ordering, a database, accounts, payments and a CMS without redesigning the front end.
